# 安全问题报告 / Reporting security issues

请通过 [Patsnap Trust Center](https://trust.patsnap.com/) 公布的[合规联系方式](mailto:compliance@patsnap.com)私下报告潜在的安全漏洞。请注明受影响的插件版本、客户端及版本、影响范围和脱敏后的复现信息。公开 Issue 适用于一般缺陷和功能需求。

Report potential vulnerabilities privately using the [compliance contact](mailto:compliance@patsnap.com) published by the [Patsnap Trust Center](https://trust.patsnap.com/). Include the affected plugin and client versions, impact, and redacted steps to reproduce. Keep credentials, customer data, and sensitive reports out of public issues.
